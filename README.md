# En Yavaş Merhaba Dünyası

## Resmi Açıklama

Bu depo, insanlık tarihinin en önemli teknolojik başarılarından birini barındırmaktadır: **En Yavaş Merhaba Dünyası**.

Neden hızlı olsun ki? Hayat zaten yeterince hızlı. Bu program, her harfi 10 saniye arayla yazarak size düşünme fırsatı verir. Belki de 'Merhaba' demeden önce hayatın anlamını sorgularsınız.

### Özellikler
- Gerçekten çalışır
- Python 3 ile yazıldı
- Her harf arasında zorunlu 10 saniye meditasyon
- Kayyum onaylı (Eskişehir 4. Ağır Ceza Mahkemesi referansıyla)
- Tamamen gereksiz ve absürt

### Nasıl Kullanılır
```bash
python3 yavas_merhaba.py
```

Sonra çay demle, çünkü bitmesini beklemen uzun sürecek.
